Use the repository-relative examples/paper-setup/README.md for context, prompt.md for the clean invocation and layout.json for the authored scene plan. All referenced assets are listed in docs/assets.json and included in library/. The manuscript DOI is 10.1103/6ftp-svh8; the models are a later reconstruction. Do not require any file from the private working project.

For the bundled paper example, include both reference images specified in layout.json by default. Preserve aspect ratios and place the hologram beside SLM and recorded intensity beside CCD, without connectors or occluding optics. Load repository-relative paths, pack image textures in the saved .blend, and inspect both camera renders for the panels. Missing source files are an error to resolve, not permission to omit panels. Record provenance; never describe supplied images as simulated results.
