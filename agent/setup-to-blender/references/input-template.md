# Input template

- Component labels and types/shapes, in optical order.
- Branches, reflected passes, selected order and rejected-order endpoints.
- Known focal lengths, separations, apertures and units; write unknown otherwise.
- Sketch file or explicit statement that only the list is available.
- Optional reference images, associated instrument and source/rights.
- Requested output width and views; default 86 mm, perspective and plan.
- Destination and files to preserve.

Ask the agent to write its interpreted scene plan and record assumptions, then build and inspect the result. Do not interpret a sketch's visual spacing as measured distance.
