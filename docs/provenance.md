# Asset provenance

Original generic visualization models are authored contributions under the project license. Catalogue renders use only library collections and no manuscript reference imagery. The catalogue independently normalizes display sizes. It does not change source dimensions.

## Example image panels

The default example and guide preview include the two supplied SLM/CCD images described in [reference-image provenance](../examples/paper-setup/reference-images/README.md). They are extracted reference imagery from the paper, not Blender-generated results, and retain their existing rights. The catalogue still contains no manuscript imagery.
