# Asset provenance

Original generic visualization models are authored contributions under the project license. Catalogue renders use only library collections and no manuscript reference imagery. The catalogue independently normalizes display sizes. It does not change source dimensions.

## Example image panels

The default example and guide preview include the two supplied SLM/CCD images described in [reference-image provenance](../examples/paper-setup/reference-images/README.md). They are extracted reference imagery from the paper, not Blender-generated results, and retain their existing rights. The catalogue still contains no manuscript imagery.

## Optical collimator

The collimator model, preview and construction source are original project contributions under the existing model/documentation and code licenses. Its preview contains no supplied reference images. The v0.4 addition extends the working library; it does not alter the archived v0.1.2 DOI release.

The bundled `examples/paper-setup/source.blend` is the original nine-component reconstruction with portable image paths, normalized panel meshes and publication surface beam envelopes. Its supplied images retain their previously documented rights. All guide camera samplers and expected exports use this same scene.

The current original-example revision adds the collimator and uses SO_Pinhole as the input 4F object and SO_Iris at the return Fourier plane. The local and published library geometry was audited; the old embedded example instances were the stale copies. All current guide images and expected/ outputs have been regenerated. Historical dated figure folders retain their prior versions.
