# Cite Blender Optical Schematics

Rodriguez-Lara, B. M. (2026). Blender Optical Schematics (Version v0.1.2) [Computer software]. Zenodo. https://doi.org/10.5281/zenodo.23994376

Use `schematics.bib` for traditional BibTeX, `schematics.ris` for reference managers, `schematics.csl.json` for CSL tools, or `schematics.txt` for plain text. These files cite the archived v0.1.2 release, published 6 November 2026.

For a specific result cite the release actually used. The all-versions DOI is https://doi.org/10.5281/zenodo.23993947; it identifies the project across releases, not a fixed snapshot. The paper DOI https://doi.org/10.1103/6ftp-svh8 is a separate scientific reference. The Blender reconstruction was developed after the paper and was not used in it.
